Superheroe

Classificador de heróis

Cliente
Projeto próprio
Ano
2026
Papel
Front-end · Consumo de API
Stack
React, REST, CSS Modules

Resumo

Interface de busca e comparação que classifica personagens por atributos, com cache local das consultas para tornar a navegação de volta instantânea.

Busca

Entrada com debounce, cancelamento de requisições em voo e cache por chave de consulta. Resultados anteriores continuam visíveis enquanto a próxima página carrega.

Comparação

Barras de atributo normalizadas pelo maior valor do conjunto selecionado, para que a leitura relativa funcione com qualquer combinação.
