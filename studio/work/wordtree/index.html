WordTree

Analisador de hierarquia de palavras

Cliente
Projeto próprio
Ano
2026
Papel
Front-end · Algoritmo
Stack
JavaScript, Canvas, Vite

Resumo

Ferramenta que monta a árvore hierárquica de um conjunto de palavras e desenha as relações em tempo real conforme o texto é digitado.

Estrutura

O texto é tokenizado e convertido em um grafo acíclico; os nós recebem peso por frequência e profundidade. O layout usa um algoritmo de tensão simples, com passo fixo para manter 60fps.

Render

Desenho em canvas 2D com camada separada para rótulos, evitando recalcular métricas de texto a cada quadro.
