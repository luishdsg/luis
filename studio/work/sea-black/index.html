Sea Black

Cadastro e classificação de funcionários

Cliente
Projeto próprio
Ano
2026
Papel
Front-end · Modelagem de dados
Stack
Next.js, TypeScript, Tailwind

Resumo

Painel administrativo para cadastrar, classificar e acompanhar equipes. O foco foi reduzir o número de telas necessárias para concluir uma operação de cadastro.

O problema

Cadastros de pessoal costumam espalhar campos obrigatórios por várias etapas, o que aumenta o abandono do formulário. A proposta foi concentrar tudo em uma tabela editável, com validação no próprio campo.

Solução

Tabela virtualizada com edição inline, estados otimistas e desfazer. A classificação por cargo é calculada no cliente para manter a filtragem instantânea, sem viagem ao servidor.
